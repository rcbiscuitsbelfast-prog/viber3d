
# 🌟 **TINYQUESTS / MINIQUESTS — FULL UI GRAND PLAN**
A mobile‑first, medieval‑fantasy, nature‑infused interface for building and sharing tiny adventures.

---

# 🧭 **1. Core UI Principles**
- **Mobile-first** (portrait primary, landscape supported)
- **Medieval fantasy aesthetic** (wood, vines, stone, parchment)
- **Friendly, whimsical tone**
- **Soft animations** (fade, slide, scale)
- **Modular components** (cards, panels, buttons)
- **Custom PNGs for key visuals** (logo, frames, buttons)
- **AI-generated art used as static assets**, animated in-engine

---

# 🎬 **2. Splash Screen**
### Elements:
- Animated sign (your MP4)
- Soft nature background (fields, trees, warm light)
- “Start” button (wooden plank)
- Optional ambient particles (floating leaves, dust motes)

### Flow:
1. Video plays
2. Fade-in Start button
3. Tap → route logic:
   - If opened via quest link → **Open Quest**
   - If new player → **Main Menu**

---

# 🏰 **3. Main Menu**
### Layout:
- Top: **Custom PNG sign** (TinyQuests / MiniQuests)
- Middle: **Vertical wooden buttons**
  - Create New Quest
  - Play Quests
  - Credits
- Top-right: **Settings cog**
- Bottom: **Coming Soon** wooden panel

### Animations:
- Buttons slide up
- Sign gently bobs or glows

---

# 🧩 **4. Create New Quest → Guided Builder Flow**
Each step uses **card-based selection** with custom PNG frames.

## **Step 1: Quest Type**
Two large cards:
- **Combat Quest**
  - “Defeat enemies and a big boss”
- **Non-Combat Quest**
  - “Puzzles, collecting, foraging, exploration”

Below them:
- **Experimental Modes (Coming Soon)**  
  - Disabled card with lock icon

---

## **Step 2: World Type**
Three cards:
- **Open World**
- **Platformer**
- **Multi-Level**

Each card includes:
- Title
- Description
- Image placeholder
- Wooden/stone frame PNG

---

## **Step 3: Template Selection**
Filtered by previous choices.

### Template Card Structure:
- Template name
- Short description
- Image preview
- Tags (Combat / Non-Combat, World Type)
- Wooden frame PNG
- Premium templates have a lock icon

Grid or scroll list depending on orientation.

---

# 🎨 **5. Customisation Hub (Entry Screen)**
This is the transition into the live world editor.

### Elements:
- Preview of the chosen template
- Button: **Enter World Editor**
- Short description of what you can customise

---

# 🛠️ **6. World Editor (Live Customisation UI)**
This is the heart of TinyQuests.

## **Layout (Responsive)**
### Portrait:
- World canvas: center
- Asset bar: bottom (scrollable horizontal)

### Landscape:
- World canvas: right
- Asset bar: left (scrollable vertical)

---

## **Asset Bar Sections (in order)**
Each section uses a stylised PNG frame:

### **1. Assets / Objects**
- Trees  
- Rocks  
- Buildings  
- Props  
- Treasure chests  
- Environmental items  

### **2. NPCs**
- Friendly NPCs  
- Quest givers  
- Merchants  
- Enemies (if combat)  

### **3. Audio & Triggers**
- Narration spots  
- Ambient zones  
- Player death sound  
- Quest completion sound  
- Hidden reveal triggers  

### **4. Boss & Rewards (Combat only)**
- Boss selector  
- Boss name input  
- Reward selector  

---

## **Monetisation Hooks (Integrated into Asset Bar)**
- Premium assets greyed out with lock icon  
- “More NPCs — Subscribe to unlock”  
- “Premium Bosses”  
- “Extra audio slots”  
- “Create your own template world”  

No backend logic — just UI.

---

## **Interactions**
- Tap asset → highlight + tooltip  
- Drag asset → drop into world canvas  
- Tap placed asset → open mini-panel:
  - Move  
  - Delete  
  - Edit (dialogue, path, behaviour)  

---
