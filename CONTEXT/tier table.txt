## 🧠 How This System Reads (Important)

- **Free users** → instant creativity, zero friction
    
- **Creator Pass** → more freedom, more expression
    
- **Pro Creator** → full control + scale
    
- **Own a World** → emotional ownership + permanence
    
- **High-Traffic Mode** → infrastructure, not status
    

Nothing feels punitive.  
Everything scales with **server cost**.

---

## 🔑 Concurrency Philosophy (Locked In)

- Total plays ≠ problem
    
- **Simultaneous plays = real cost**
    
- Queueing is normal, expected, fair
    
- High-Traffic Mode is framed as _capacity_, not privilege
    

This protects you from:

- viral streamers
    
- classroom spikes
    
- coordinated raids
    
- accidental outages
    

---

## 🚦Operational Notes (For You / AI Agents)

- Concurrency limits enforced per-world
    
- Graceful queue message when full
    
- Optional temporary boosts (event-based)
    
- Pro worlds get priority scaling
    
- Owned worlds are capped but reliable
