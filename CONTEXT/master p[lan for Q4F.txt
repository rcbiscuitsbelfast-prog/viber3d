## 🧱 Firestore Data Model (Lock This)

```ts
quests/{questId} {
  ownerId: string
  title: string
  templateWorld: 'forest' | 'meadow' | 'town'
  gameplayStyle: 'combat' | 'nonCombat' | 'mixed'
  createdAt: timestamp
  expiresAt: timestamp | null
  isPublished: boolean

  entities: Entity[]
  tasks: Task[]
  triggers: Trigger[]

  analytics: {

    completions: number
  }
}
```
