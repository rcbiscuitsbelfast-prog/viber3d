### Updated Concept Tweaks for Browser-Only
- **Platform**: Pure web app (no downloads). Users access via URL, build quests in-browser, export shareable links/QR codes. Recipients play directly in their browser (mobile-friendly via responsive design).
- **Sharing**: Integrate social buttons (e.g., "Share on X/FB/WhatsApp") for links. QR codes generated on-the-fly (using a lib like qrcode.react).
- **3D Assets**: Switch from 2D isometric to 3D top-down view (like a simplified Zelda in browser). Use free/low-poly models from sources like Sketchfab or Kenney.nl. Assets: 3D models for themes (forest trees, crypt tombs), NPCs (animated characters), enemies (simple rigs).
- **Freemium Details**:
  - **Free Tier**: Unlimited quests, but limited to 5 recipients per quest (track via user auth). Basic assets (2-3 themes, 5 NPCs/enemies, short audio <10s). No ads.
  - **Paid Tier** ($4.99/month or $29.99/year via Stripe): Unlimited recipients, premium assets (more themes, custom models, longer audio), advanced customizations (e.g., particle effects, custom 3D imports), priority support.
  - Analytics: Track shares/opens to gamify (e.g., "Your quest was played 10x—unlock a badge!").

#### src/context/AuthContext.jsx (Freemium Enforcement)
```jsx
import { createContext, useState, useEffect } from 'react';
import { initializeApp } from 'firebase/app';
import { getAuth, onAuthStateChanged } from 'firebase/auth';
import { getFirestore, doc, getDoc } from 'firebase/firestore';

const firebaseConfig = { /* Your Firebase config here */ };
const app = initializeApp(firebaseConfig);
const auth = getAuth(app);
const db = getFirestore(app);

export const AuthContext = createContext();

export const AuthProvider = ({ children }) => {
  const [user, setUser] = useState(null);
  const [isPremium, setIsPremium] = useState(false);

  useEffect(() => {
    const unsubscribe = onAuthStateChanged(auth, async (currentUser) => {
      setUser(currentUser);
      if (currentUser) {
        const userDoc = await getDoc(doc(db, 'users', currentUser.uid));
        setIsPremium(userDoc.data()?.premium || false);
      }
    });
    return unsubscribe;
  }, []);

  return (
    <AuthContext.Provider value={{ user, isPremium }}>
      {children}
    </AuthContext.Provider>
  );
};
```

#### src/pages/Builder.jsx (3D Builder Core)
```jsx
import { useState, useContext } from 'react';
import { Canvas } from '@react-three/fiber';
import { OrbitControls, Environment } from '@react-three/drei';
import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader';
import RecordRTC from 'recordrtc';
import Howler from 'howler';
import QRCode from 'qrcode.react';
import { AuthContext } from '../context/AuthContext';
import { getFirestore, addDoc, collection } from 'firebase/firestore';

const db = getFirestore();

function Builder() {
  const { isPremium } = useContext(AuthContext);
  const [assets, setAssets] = useState([]); // e.g., [{type: 'model', position: [0,0,0], url: 'forest.glb'}]
  const [audio, setAudio] = useState(null);
  const [questId, setQuestId] = useState(null);
  const [recorder, setRecorder] = useState(null);

  const startRecording = () => {
    navigator.mediaDevices.getUserMedia({ audio: true }).then(stream => {
      const rec = new RecordRTC(stream, { type: 'audio' });
      rec.startRecording();
      setRecorder(rec);
    });
  };

  const stopRecording = async () => {
    recorder.stopRecording(async () => {
      const blob = recorder.getBlob();
      // Upload to Firebase Storage, get URL, setAudio(url);
      // For demo: setAudio(URL.createObjectURL(blob));
    });
  };

  const addAsset = (type, url) => {
    if (!isPremium && assets.length >= 5) return alert('Upgrade for more assets!');
    setAssets([...assets, { type, url, position: [Math.random()*10, 0, Math.random()*10] }]);
  };

  const saveQuest = async () => {
    const questData = { assets, audio, recipients: [] }; // Track sends for freemium
    const docRef = await addDoc(collection(db, 'quests'), questData);
    setQuestId(docRef.id);
  };

  const shareLink = questId ? `${window.location.origin}/play/${questId}` : '';

  return (
    <div style={{ display: 'flex', height: '100vh' }}>
      <div style={{ width: '20%', padding: '10px' }}>
        <button onClick={() => addAsset('model', '/assets/forest.glb')}>Add Forest</button>
        <button onClick={startRecording}>Record Voice</button>
        <button onClick={stopRecording}>Stop</button>
        <button onClick={saveQuest}>Save & Share</button>
        {questId && (
          <>
            <QRCode value={shareLink} />
            <a href={`https://twitter.com/intent/tweet?url=${shareLink}`}>Share on X</a>
          </>
        )}
      </div>
      <Canvas>
        <OrbitControls />
        <Environment preset="forest" />
        {assets.map((asset, i) => (
          <primitive key={i} object={new GLTFLoader().load(asset.url)} position={asset.position} />
        ))}
      </Canvas>
    </div>
  );
}

export default Builder;
```
